# Nonprofit preview, 14 November 2026

Review route: `/design-preview`. The existing public homepage and signed-in application keep their current design while this direction is reviewed.

## Verified references

The Webby Awards nonprofit category lists the Obama Foundation as the 2025 Webby Winner and People's Voice Winner, and SOMA Surf Therapy as the 2024 People's Voice Winner:
https://winners.webbyawards.com/winners/websites-and-mobile-sites/general-desktop-mobile-sites/charitable-organizationsnon-profit

Sites inspected: https://www.obama.org/ and https://www.somasurf.org/.

Adapted patterns: full-width photographic opening, prominent editorial headings, direct navigation, generous spacing, and simple participation links. Original brand, text and layout implementation. No copied source code, proprietary typefaces or imagery from the reference organizations.

## Typography

Noto Sans Arabic for navigation and body, Noto Naskh Arabic for headings. Arabic tracking remains normal. Source Sans 3 for English body, Oswald for English display headings. Fonts are self-hosted, free under SIL OFL; licenses are in `public/licenses`. Navigation is 16px semibold, body starts at 17px. The preview intentionally changes both the typefaces and typographic hierarchy.

## Data and interaction

Public events, news and optional video/poster use the existing public API. Empty sections remain honest, no invented events or news. Join and login links open existing account forms. Preview supports RTL/LTR, mobile navigation and light/dark themes. No database or authentication-policy changes.
